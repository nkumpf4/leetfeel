# LeetFeel

Type the LeetCode solution the AI already wrote — just to feel something again.

A meme typing test: pick a problem and a language, then type a real solution
character-for-character (Classic mode) or spam Tab to accept autocomplete
suggestions (Tab Complete mode). Paste is disabled. Obviously.

**Play it:** it's a single static `index.html` — open it, or deploy the repo
to any static host (Vercel: no build command, root output).
